SEKALI DI AWAL / SALIN KE CHAT

Siapkan folder ini untuk membuat konten OTCA. Salin repo https://github.com/otcainovasi-sys/ai-content-creator.git langsung ke folder ini tanpa menimpa file.

Ikuti bagian Instalasi di README sampai tes lolos. Saya pengguna nonteknis; pandu jika ada tindakan yang perlu saya lakukan. Jangan membuat konten dahulu.

Tunggu sampai agen menyatakan SIAP. Jika perlu memasang Node.js atau Git, agen akan memandu.

3

Kirim brief kontennya.

Setelah siap, buat chat baru dalam proyek yang sama untuk satu konten, lalu salin:

PESAN UNTUK MULAI MEMBUAT KONTEN

Brand: [Official OTCA / Info Jerman / Jepang Koey / Ciao Manda].
Tema: [temanya]. Jumlah slide: [jumlah, atau bebas]. Brief: [pain point dan angle, jika ada].

Buat carousel sesuai standar brand di folder knowledge. Riset dan pastikan faktanya, pakai skill humanizer untuk copy, lalu variasikan maskot dan susunan isi supaya tidak mirip konten sebelumnya.

Tandai fakta yang perlu dicek. Tunjukkan hasilnya kepada saya sebelum disimpan ke GitHub.

4

Kalau belum cocok, minta perbaikan.

  • Logo, warna, dan font sesuai brand.
  • Tulisan mudah dibaca, tidak menempel, dan kotak tidak terlihat kosong.
  • Maskot tidak menutupi tulisan atau gambar penting.
  • Fakta, harga, dan bonus sudah dipastikan tim.
CONTOH PESAN PERBAIKAN

Pada slide [nomor], tolong [jelaskan perubahannya]. Contohnya: jarak daftar terlalu renggang dan ikon terlalu kecil.

Bandingkan dengan feed live, jalankan QA ketat, lalu tampilkan versi yang sudah diperbaiki.

5

Kalau sudah cocok, ambil hasilnya.

PESAN SETELAH COCOK

Konten ini sudah cocok. Tunjukkan lokasi file PNG dan caption-nya, lalu simpan spec-nya ke GitHub dengan commit dan push.

Sesudah file diterima: lihat semua slide di HP, lalu kirim lembar review.png ke Mbak Nia. Sistem tidak pernah menayangkan konten sendiri.

Mau menambah gaya baru: kirim PDF feed live ke chat, lalu minta agen menganalisis dan membandingkannya dengan hasil kita sebelum aturan diubah.
