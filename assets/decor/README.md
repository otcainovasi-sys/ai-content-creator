# Ornamen dekoratif

Semua ornamen di folder ini dibuat sendiri oleh `scripts/make-decor.mjs` (`npm run decor`), jadi bebas lisensi dan milik proyek.
Warna diatur di `config/decor.json`, penempatan per brand di `config/brands/<brand>.json` -> `decor`.

| Ornamen | Brand |
|---|---|
| `flow-lines` (garis mengalir gradasi) | OTCA (emas), Ciao (emas), Info Jerman, Koey |
| `blob-*` (bentuk organik gradasi + grain) | Semua |
| `sparkle`, `rings`, `dots` | Semua |
| `sheen` (kilap sudut) | OTCA |
| `seigaiha`, `cloud` (motif Jepang) | Jepang Koey |
| `wave` (pita gelombang bawah) | Info Jerman, Ciao Manda |

Paket Coolshapes (MIT) sempat dicoba, tetapi menjalankan kodenya ditolak oleh pengaman otomatis, jadi tidak dipakai.
